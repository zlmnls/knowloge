# Work Memory · 个人工作记忆与知识图谱

Windows 本地工作记忆与知识图谱构建工具。专为**飞书语音转文字（带说话人标记） / 会议讨论 / 需求沟通**设计，支持闲聊降噪、Ontology 实体抽取与同名归一、交互式知识图谱构建、时序事实演进追踪，以及围绕实体的 **Living Wiki（一实体一主文档增量演进）**。

## 启动方式

1. 安装 Python 3.10+（仅使用标准库，无需安装任何第三方依赖）
2. 双击 `run.bat`（或运行 `python app.py`）
3. 浏览器打开 `http://127.0.0.1:8765`
4. 在「⚙️ 冷启动锚点与设置」页配置：
   - **个人冷启动锚点卡（Seed Profile）**：填写你的姓名/角色与核心系统背景，消除初次实体抽取时的上下文盲区。
   - **模型 API 设置**：配置兼容 OpenAI Chat Completions 的 API Base URL、模型名与 API Key。

## 核心能力与工作流

1. **🎙️ 飞书转写导入与说话人快速映射**
   - 自动识别粘贴文本中的 `说话人 1`、`说话人 2` 等标签，支持一键映射为真实姓名/角色。
   - 自动识别并滤除日常寒暄、快递、午饭等纯闲聊噪音片段。
2. **🧩 实体抽取、同名归一与禁抽黑名单（Entity Resolution）**
   - 顶层 Ontology 固定为 4 类稳定对象：`BusinessEntity`（业务实体）、`SystemEntity`（系统实体）、`Project`（项目专项）、`Person`（干系人/团队）。
   - **同名与同音字自动对齐**：每次抽取自动注入已有实体及口语别名表（如将飞书转写的“欧姆S”、“老订单”自动对齐到 `OMS订单系统`）。
   - **可视化审核卡片**：支持一键改名、合并重复实体、或将泛化词（如“接口”、“前端”）拉入禁抽黑名单。
3. **🕸️ 交互式知识图谱与本体管理**
   - 内置力导向知识图谱画布，支持按类别筛选、搜索别名、拖拽缩放及点击查看 1 跳上下游邻居关系。
   - 支持手动增删种子实体、合并重复节点、维护图谱关系边。
4. **📚 围绕实体的 Living Wiki 与时序事实流（Facts）**
   - **Living Wiki**：告别同名文件碎片化，每个核心实体对应唯一主文档 `10_wiki/{Category}__{Entity}.md`，包含【当前生效规则】、【上下游图谱边界】、【待定争议项】、【演进历史 Changelog】四大板块，每次审核入库自动增量合并。
   - **时序事实演进**：区分 `confirmed`、`discussing`、`proposed`、`historical` 状态；当新确认规则与旧规则冲突时自动提示并将旧记录归档为 `historical`，支持一键回溯原始录音文本。

## 数据目录结构 (`knowledge-base/`)

- `00_sources/`：原始飞书录音转写与对话记录（`SRC-*.md`）
- `10_wiki/`：围绕实体的 Living Wiki 活文档（`{Category}__{Entity}.md`）
- `20_facts/`：按月追加的时序事实流（`YYYY-MM.jsonl`）
- `30_ontology/`：
  - `schema.yaml`：Ontology 实体分类、关系类型与抽取边界铁律
  - `profile.json`：个人冷启动锚点卡配置
  - `entities.json`：正式实体库（含 `aliases` 口语别名表）
  - `relations.json`：正式知识图谱关系边库
  - `blacklist.json`：禁抽泛化词黑名单
  - `candidates.jsonl`：历次审核入库审计日志
